# Availability and Reproducibility

The Statistical Decision Tree is freely accessible as a browser-based application at https://dariho.github.io/decision-tree/. The project source is maintained at https://github.com/dariho/decision-tree. The repository contains the website code, language resources, example datasets, jamovi screenshots, assumption guidance, static decision-tree diagrams, and a companion R Markdown project. The website runs entirely in the user's browser and does not upload or process user data on a server.

The example datasets are provided as CSV files so that analyses can be reproduced in jamovi or R. The R project includes package-installation checks, executable code, and short descriptions of the represented procedures. Reproduction of graphical workflows may additionally require the jamovi modules named in the procedure instructions. Because R packages, jamovi, and third-party jamovi modules can change, the software and module versions used for the publication release should be reported alongside the archived materials.
